# 📈 形態訓練營

三角形・旗形・楔形（7 個形態）嘅網頁練習。全部為模擬教學圖，只作學習，非投資建議。

開啟方法：Settings → Pages → Branch: main / root。單一個 `index.html`，無需安裝，手機都用得。

**多人學習**：每次開啟先揀學員（可新增、改名、刪除），每人嘅進度、錯題本、掌握度分開記錄。紀錄存喺該部機嘅瀏覽器，換機可以匯出／匯入。

## 練習模式

| 模式 | 做乜 |
|---|---|
| 🎯 智能練習 | 自動揀最需要練嘅形態同難度，7 項分析（名稱、原理、偏向、入場、止蝕、目標、出錯原因） |
| 📚 學習模式 | 示範例題（有入場／止蝕／目標標示）、口訣、示意圖、易混淆對比，之後主動回憶 |
| ⚡ 快閃辨識 | 圖只顯示幾秒就隱藏，練第一眼直覺；顯示時間會按表現自動調節 |
| ⚖️ 對比辨別 | 兩幅相似形態並排，揀出指定嗰幅；自動針對你最常混淆嘅一對 |
| ✏️ 畫線練習 | 自己喺圖上畫阻力／支持線，計貼合度同斜率，再命名形態 |
| 📕 錯題本 | 保留原圖（同一隨機種子），隔一日重做，全對先移出；可寫自我解釋 |
| 🧩 經典模式 | 自選初級／中級／高級（含假突破），每輪 3 題 |
| 📘 課程 | J Law 11 課（VCP、趨勢線、平行通道、均線、M.E.T.A.、拉回買入、見底／見頂訊號、套牢與翻身）＋ 6 課建議補充（四階段、杯柄／雙底／頭肩、相對強度 RS、量價、財報風險、交易心理），附建議學習次序，每課可主動回憶 |
| 🎯 M.E.T.A. 圖表 | 第二階段回調圖：自己搵出前浪頂、20／50MA、UTL、低量拉回、DTL 突破邊幾個重疊，判斷入唔入場同止蝕 |
| 🚀 強勁趨勢辨識 | 強勁趨勢 vs 一般趨勢並排：少碰 20MA、順勢放量、大升細回 |
| 🧠 概念快問 | 98 題概念題，間隔重複，答錯會連返去對應課堂 |
| 🧮 情境計算 | 每次隨機出數：回本升幅、R 倍數、勝率 vs 盈虧比、M.E.T.A. 優勢判斷、出貨日計數 |
| 📈 VCP 辨識 | 模擬 VCP 圖（有 50MA／200MA），分辨有效定無效（趨勢唔啱、收縮擴大、最後收縮 >10%），數收縮、定 Pivot 同止蝕 |
| 📊 統計與設定 | 掌握度、七項準確率、信心校準、混淆矩陣、得分走勢、匯出／匯入進度 |

## 用咗嘅學習法

- **間隔重複（SM-2）**：答錯 10 分鐘後再到期，同一輪隔 2 題重出；答啱間隔 1 → 3 → 7… 日拉長。
- **主動回憶**：知識卡先自己講重點，再對答案自評。
- **交錯練習**：避免連續同一形態／同類。
- **對比辨別**：逐項列出兩個形態嘅分別（上軌、下軌、收窄定平行、旗桿、偏向）。
- **生成效應**：自己畫線。
- **信心校準**：「🎲 估」中唔當識；冇剔但答錯＝盲點。
- **自我解釋**：答錯後寫低原因，重做時顯示。
- **漸退鷹架**：新形態先幫你畫好趨勢線，掌握度上升後移除。
- **適度難度**：每個形態有 Elo 評分，揀預期正確率約 70% 嘅難度。
- **事前驗屍**：作答前寫低可能錯喺邊（可喺設定關閉）。

J Law 內容整理自公開 YouTube 教學筆記；「建議補充」為一般交易知識。只作學習用途，非投資建議。
